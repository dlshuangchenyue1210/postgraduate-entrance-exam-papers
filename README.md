# 考研数学历年真题（数字化重排）

考研数学历年真题的 Markdown 数字化版本：公式可检索、可正常渲染，几何配图全部为 SVG 矢量，适合用 Obsidian 等工具做深度阅读与二轮复习。

## 特点

- **纯 Markdown + LaTeX**：公式使用 `$...$` / `$$...$$`，任何支持 MathJax / KaTeX 的渲染器均可正常显示。
- **零位图**：所有几何图、函数图均为 SVG 矢量，任意缩放不失真，无需依赖位图截图。
- **原卷结构**：保留大题划分与分值，选择题选项统一为 `- (A) ...` 单列列表，便于折叠与自测。
- **一题一图**：题图与各选项图分离为独立文件，不做多图拼贴。

## 目录

```text
src/md/
└── math-2/          # 数学二
    ├── 2005/
    │   ├── 2005.md
    │   └── images/*.svg
    ├── 2006/
    └── ...
```

配图命名：`[年份]_[科目]_q[题号].svg`，选项独立图追加选项字母，例如 `2009_math2_q06_a.svg`。

## 使用

1. 用 Obsidian 打开本仓库，或将 `src/md/` 复制进已有 vault。
2. 确认已启用 MathJax / LaTeX 公式渲染。
3. 打开 `src/md/math-2/[年份]/[年份].md` 即可阅读。
